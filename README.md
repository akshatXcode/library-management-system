# Library Management System

##  Project Overview

The **Library Management System** is a simple web-based application designed to help manage books in a library efficiently. The system allows users to add books, view the list of available books, issue books, and return them.

This project demonstrates how basic web technologies can be used to digitize traditional library processes and improve organization, accessibility, and efficiency.

---

##  Problem Statement

Many small libraries and educational institutions still manage books manually using registers or spreadsheets. This creates several problems:

* Difficulty tracking issued and returned books
* Time-consuming record management
* High chances of human error
* Lack of a centralized system

The **Library Management System** solves these problems by providing a simple digital platform for managing books and their availability.

---

## Features

* **Add Books** – Users can add new books with title and author details.
* **View Book List** – Displays all books currently stored in the system.
* **Issue Books** – Mark books as issued when borrowed.
* **Return Books** – Update status when books are returned.
* **Instant Updates** – Book status updates immediately in the interface.
* **Simple User Interface** – Clean and easy-to-use design.

---

## Technologies Used

This project was built using basic web technologies:

* **HTML** – Structure of the web page
* **CSS** – Styling and layout
* **JavaScript** – Application logic and interaction

These technologies make the project lightweight and easy to understand for beginners.

---

##  System Workflow

1. The user enters book details (title and author).
2. The system stores the book information in the application.
3. The book appears in the list of available books.
4. When a book is issued, its status changes to **Issued**.
5. When returned, the status changes back to **Available**.
